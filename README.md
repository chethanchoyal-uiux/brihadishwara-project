# Brihadishwara Temple website

Home page for the Brihadishwara Temple (Thanjavur) interpretive site.

## Run

```bash
cd website
npm install
npm run dev
```

## Content sources

- Writeup: `Final writeup and photos/writeup/`
- Photos: `Final writeup and photos/photos/`
- Design layout reference: Gospel Webflow demos (structure only; no template animations)
- Client wireframe: video hero, intro, tribute, section panels
